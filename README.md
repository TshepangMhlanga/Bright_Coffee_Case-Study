# ☕ Bright Coffee Shop Sales Analysis

## 📌 Project Overview
This project analyzes transactional data from Bright Coffee Shop to uncover insights that will guide the new CEO in growing revenue and improving product performance. The dataset captures daily transactions, including product type, unit price, and quantity sold. Using SQL, Databricks, and visualization tools, we transform raw data into actionable business intelligence.

---

## 🎯 Objectives
- Identify products that generate the most revenue.
- Determine peak sales times during the day.
- Track sales trends across products and time intervals.
- Provide recommendations to improve sales performance.

---


---

## 🛠️ Tools & Technologies
- **Planning**: Miro, Figma  
- **Data Processing**: Databricks, SQL Server, MySQL Workbench, DBeaver  
- **Visualization**: Excel, Power BI, Tableau, Google Sheets  
- **Presentation**: PowerPoint, Canva  

---

## 📊 Key Insights to Deliver
- **Revenue by product category**  
- **Peak time intervals** (grouped into 30-min or 3-hour buckets)  
- **Best-selling vs underperforming products**  
- **Total revenue calculations** (`unit_price * transaction_qty`)  
- **Units sold by product type**
